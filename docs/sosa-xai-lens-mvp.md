# Sosa XAI Lens MVP

This change introduces the first reusable Android UI/model slice for the Sosa XAI Lens in the existing Kotlin/Jetpack Compose application.

## Included

- `XaiProvenance.kt`: typed evidence, context, action status, and limitation models.
- `XaiLensPanel.kt`: expandable Material 3 panel with Evidence, Context, Actions, and Uncertainty/limitations sections.
- `XaiProvenanceTest.kt`: unit tests for missing provenance and auditable memory labels.

## Truthfulness and safety behavior

- Missing provenance is rendered as `Details unavailable`, not as a claim that no evidence was used.
- Saved memory without an auditable memory ID is labelled unverified.
- Tool actions use explicit statuses, including failed, blocked, skipped, and unknown.
- No confidence percentage is generated by this model or UI.
- The component has no API keys, provider SDK calls, or network access.

## Integration boundary

The current repository's chat flow stores `ChatMessageEntity` records and calls the existing repository/provider service, but no answer-scoped provenance API or durable source/action event stream was found in the inspected files. The panel is therefore added as a reusable component but is not yet attached to each chat message. Wiring fabricated placeholder sources into live answers would mislead users; the next step is to add backend-produced provenance and then connect the component to it.

## Verification

The GitHub source was inspected to identify the Android/Kotlin/Jetpack Compose stack and the existing chat screen/view model. Automated Gradle tests and an Android build have not been run in this environment. Run `./gradlew :app:testDebugUnitTest :app:assembleDebug` in a configured checkout before merging.
